# Cyber Training 4 All — redesign preview

This is a local redesign preview. It does not modify the GitHub repository.

## Design direction
- Dark navy / slate cyber aesthetic with restrained teal and blue accents.
- Responsive hero section, clearer calls to action, audience cards, and recent insights.
- Shared branded header, responsive navigation, and mission-focused footer.
- Redesigned student, executive, employee, about, and insights landing pages.
- Focus-visible states, skip-to-content link, semantic landmarks, reduced-motion support, and responsive layouts.

## Review and deployment
The existing content assets, PDFs, posts, Jekyll configuration, analytics include, and site URLs are retained. Before publishing, run the site's normal GitHub Pages/Jekyll build and check the rendered pages at desktop and mobile widths. Review the profile text on the About page and confirm it is still current before publishing.
