RHEL 9 Bash Simulator

  
A browser-based simulation of a Red Hat Enterprise Linux 9.4 server shell. The filesystem, users, services, packages and history are simulated and saved in your browser's local storage.

  
Keyboard

  

    
Tab complete commands/paths (twice to list)
↑/↓ command history

    
Ctrl+C cancel line / prompt
Ctrl+L clear screen

    
Ctrl+A/E start/end of line
Ctrl+U/K cut before/after cursor

    
Ctrl+D logout (empty line)
!!, !n, !str history expansion

  

  
Shell features

  
Pipes |, redirection > >> < 2> 2>&1 &>, &&/||/;, globbing, $VAR, ${VAR:-x}, $(cmd), $((math)), aliases, for/while/if, [ ]/[[ ]], scripts (./script.sh, bash file, source).

  
RHEL specifics

  
sudo (any non-empty password), su -, dnf/yum/rpm with installable packages (tree, wget, httpd, nginx, net-tools, epel-release → htop), systemctl, journalctl, firewall-cmd, SELinux (getenforce, sestatus), nmcli, ip, ss, subscription-manager, hostnamectl, permissions & ownership enforcement.

  
Editors

  
vi/vim: i insert, Esc normal, :w :q :wq :q!, dd, x, o, G/gg, u.  nano: Ctrl+O/S save, Ctrl+X exit, Ctrl+K/U cut/paste line.

  
Limits

  
No real network or processes — network tools return simulated results. Interactive full-screen programs (top, less) print a snapshot. Reset VM restores the original machine.
